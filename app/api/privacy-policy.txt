DOST PRIVACY POLICY
Effective date: November 14, 2026

ABOUT THIS POLICY
Dost is an AI companion application for Android. This policy describes the information the current app stores on the device, what it sends to Dost's API server and to AI providers, how long the server archive is kept, and what is deleted when you remove a friend or remove the app. It matches this version of the app. Firebase Authentication provides sign-in, but profile, friend, and memory data is not synchronized to a cloud service. Chat messages are sent to Dost's API server as described below. You can export or import local data and request deletion of this installation's indexed server archive from Settings.

1. INFORMATION STORED ON YOUR DEVICE
Dost stores the following information in the app's private storage on your Android device:
- Your profile information, including name, email, age, and gender.
- A random installation id created on the device.
- Friend profiles, selected friend photos, schedules, time zones, and relationship scores.
- Chat history, conversation summaries, and facts learned from conversations.
- Language, preferred AI model, anonymous analytics preference, unread counts, and other app settings.
- Compressed copies of photos that you attach to chat messages.

Chat transcripts are stored as per-friend files under the app's private messages directory. Memories, summaries, and settings are stored in the app's private preferences. The email in your local profile is stored on the device; Firebase Authentication separately processes your sign-in email/password or Google account identity. Settings can export your profile, friend profiles, memories, summaries, transcripts, and available chat-image attachments to a passphrase-encrypted JSON file, or import that file on a fresh install. The backup uses AES-256-GCM with a key derived from your passphrase using PBKDF2-HMAC-SHA256. The passphrase is not stored or sent to Dost; if you lose it, Dost cannot recover the backup. The export does not include your OpenRouter API key or installation id. Older unencrypted JSON exports remain importable; protect those files yourself. Friend-avatar references may point to files or URIs that are not available on another device.

Chat messages and chat-photo attachments are also sent to Dost's API server and AI services as described below. A friend photo selected as an avatar stays on the device. Choosing that photo does not upload it. A photo downloaded for a catalog friend is cached on the device.

Android backup and device-to-device transfer exclude the app preferences file (dost_local_data), the messages directory, the chat_images directory, and cached system-friend photos (system-friend-photos). Those files stay on the device.

2. INFORMATION SENT TO DOST AND AI SERVICES
When you request an AI response, Dost sends the following to Dost's API server for that turn:
- The message you just wrote and the earlier messages in the current session.
- The fictional friend's persona: name, age, gender, personality, interests, and the other profile fields the app uses so the character can stay in character.
- Facts the app has learned about you from earlier messages, up to the 200 most recent saved facts.
- Summaries of ended sessions, up to the seven most recent summaries.
- That friend's friendship score and love score.
- Your time zone and the friend's time zone.

This can include personal information you choose to share in the conversation, such as your name, preferences, relationships, interests, or other details in your messages. The age stored on your profile is not sent as its own field. It can still be included if you stated it in a message or if the app saved it as a learned fact. Requests to generate a fictional friend profile send that friend's name, age, and gender.

The API server forwards AI prompts to OpenRouter, which routes them to the selected model provider. Chat requests and separately uploaded chat messages are archived on Dost's server for service operation and troubleshooting. The archive may contain user and AI messages, message timestamps and identifiers, the selected model ID, friend and user display names, the server-observed IP address used to organize the archive, chat-photo attachments, and, for lines written by the current server, the installation id. The archive is stored in folders named from the display name, that IP address, the friend name, and the session id. The server also keeps an index of those session folders for each installation id. Lines written before that index existed do not contain the installation id. API keys are not written into conversation logs.

If you enable **Share anonymous event counts** in Settings, the app sends only an allowlisted event name when an action occurs: opening a friend profile, saving or forgetting a memory, retrying a failed send, starting a first message to a friend, saving a shared ritual, turning off or pausing friend-initiated messages, or completing an automatic friend reply. These requests do not include message content, profile details, account data, an installation id, or a client-supplied timestamp. Dost stores daily event totals for 90 days, without a user or device identifier. The API host may see your IP address as part of the network request. Turning the setting off stops future event requests; because the stored values are aggregate counts, individual past events cannot be removed.

OpenRouter and the selected model provider may process request data under their own privacy policies and terms. Dost does not control their independent retention or deletion practices. Please do not share passwords, API keys, authentication codes, financial-account credentials, or other highly sensitive information in conversations.

3. RETENTION AND DELETION
Removing a friend in the app deletes that friend's local data. The app removes the friend from the on-device friend list, reads image paths from the saved transcript, then deletes that friend's chat transcript file, referenced chat-photo files, learned memories, session summaries, unread count, current-session marker, and scheduled-reply flag. It also deletes the friend's app-private catalog photo copy, drops that friend's chat from memory, and cancels pending background work for that friend.

That deletion does not remove:
- The server conversation archive described below.
- Your profile (name, email, age, gender), installation id, language, model choice, or optional OpenRouter key.
- The original gallery photo you picked as an avatar. The app does not delete the gallery original.
- The shared system-friend catalog on the server. Removing a catalog friend deletes only your local copy of that character.

Chat-photo files are stored in the app's chat_images directory. When you remove a friend, the app reads image paths from the saved transcript and removes the transcript and referenced chat-photo files. It also deletes that friend's cached catalog photo.

This version has no control that deletes your profile or all local Dost data at once. Clearing Dost's app storage or uninstalling the app removes the local profile, friend list, transcripts, memories, settings, and other files the app stored in its private directories. Uninstalling does not delete data already sent to the server.

Dost server conversation archives are retained for no more than 3,650 days (10 years) after the most recent activity in each conversation session. Activity is the last modification time of that session's archive file. A scheduled server cleanup removes expired session archives and their attached chat-photo files, including older archive files stored directly in the archive directory. The cleanup job does not run when you delete a friend, clear storage, or uninstall. The 10-year limit is Dost's chosen retention period.

Optional anonymous daily event totals are retained for 90 days and then removed. They are separate from chat archives and are not associated with an installation id.

Use Settings > Delete server archive to ask the API to remove the conversation sessions and attached images indexed for the current installation id. A small hashed-installation deletion marker remains to prevent delayed messages created before deletion from being archived again; new messages can still be archived. This removes server records written by versions that stored and indexed that id; removing a friend, clearing app storage, or uninstalling does not make this request automatically. Archives written before install-id indexing existed cannot be associated with an installation by this control and remain subject to the 3,650-day cleanup. The app does not display the installation id, and server archives are not indexed by your Firebase account. If the delete request cannot reach the server, the archive remains until a later successful request or the scheduled cleanup.

Once data has been sent to OpenRouter or a model provider, their own deletion and retention policies apply.

The 3,650-day period applies to Dost's active server archive. Any infrastructure backup copies, if retained by a hosting provider, may follow a separate provider backup schedule. The cleanup job does not purge provider-managed backups.

4. OPENROUTER API KEY
If you provide your own OpenRouter API key, Dost stores it encrypted on your device using Android Keystore-backed encryption. When making a request, the app sends the key over HTTPS to Dost's API, which forwards it to OpenRouter and does not store it. You are responsible for protecting your key and any charges made through your OpenRouter account. If you leave the key blank, the API may use a server-configured key.

5. PHOTOS AND DEVICE PERMISSIONS
Dost uses Android's file picker when you choose a friend photo. The selected avatar URI is stored on your device and is not uploaded by the avatar feature. If you attach a photo to a chat message, Dost compresses it and sends it to the API server and AI provider as part of that request; a copy is kept in the server conversation archive until that archive expires or is removed.

The optional floating chat feature requires Android's draw-over-other-apps permission. Dost uses this permission to show the floating chat bubble and panel when you enable the feature.

6. DATA SHARING, ANALYTICS, AND ADVERTISING
Dost does not use advertising or third-party tracking services. Firebase Authentication processes your account identity for email/password or Google sign-in, email verification, and password reset under Firebase's own privacy and retention practices; it does not sync your local Dost profile or conversations. Anonymous usage analytics are optional and off by default. When enabled, Dost's API host receives only allowlisted event names and stores daily event totals for 90 days; it does not receive message content, profile details, account data, or installation ids for analytics. The host may see your IP address as part of normal HTTP requests. Chat and profile-generation data is separately shared with Dost's API host, OpenRouter, and the model provider selected for the request to provide AI functionality.

7. AGE AND AUDIENCE
Registration requires a whole-number age from 13 through 120 and rejects ages under 13. Ages 13 through 17 may use the app. The romantic relationship meter and romantic prompts are turned off when the user or friend is under 18, or when either age is missing or unusable. The app does not verify the age entered or ask for parental consent. There is no children's mode and no parental controls.

Dost does not provide a child-directed service.

8. CHANGES TO THIS POLICY
We may update this Privacy Policy when the app or its data practices change. We will post the updated policy at the published policy location and revise the effective date.
